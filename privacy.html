Natura dell'applicazione

MCP Multiaccount è uno strumento personale e non commerciale, eseguito localmente sul computer dello sviluppatore e utilizzato esclusivamente con i suoi account Google. Non è offerto a terzi.

Dati a cui accede

Tramite le Gmail API e previa autorizzazione OAuth esplicita, l'applicazione può accedere a: messaggi email e relativi metadati, bozze, etichette. L'accesso avviene solo su richiesta diretta dell'utente.

Come vengono usati e conservati i dati

  • I token di accesso OAuth sono salvati solo sul computer locale dell'utente.
  • L'applicazione non ha server propri, non memorizza copie delle email e non crea database.
  • Il contenuto delle email viene trasmesso solo all'assistente AI usato dall'utente stesso (Claude, di Anthropic), nel momento in cui l'utente lo richiede.
  • I dati non vengono venduti, ceduti, condivisi con terzi né usati per pubblicità.

Google API Services User Data Policy

L'uso e il trasferimento delle informazioni ricevute dalle API Google da parte di MCP Multiaccount rispettano la Google API Services User Data Policy, inclusi i requisiti di Limited Use.

Revoca dell'accesso

L'accesso può essere revocato in qualsiasi momento da myaccount.google.com/permissions e cancellando i file dei token dal computer locale.
